# MUD RACING — квадроспорт, гонки с водными препятствиями

Браузерная аркадная игра: парные заезды квадроциклов по трассе из трёх грязевых ванн.

## Структура проекта

```
index.html        разметка + CSS интерфейса, подключает четыре скрипта
src/core.js       физика, трасса, ИИ, жеребьёвка (без DOM — работает и в Node)
src/sound.js      процедурный звук на WebAudio (двигатель, всплески, светофор)
src/render.js     отрисовка сцены на canvas 2D: трасса, квадроцикл, HUD
src/game.js       состояния игры, интерфейс, ввод, чемпионат
build.py          сборка в один автономный файл
```

## Запуск

Локально достаточно открыть `index.html` — скрипты грузятся обычными
`<script src>`, сервер не обязателен (Chromium и Firefox разрешают это для
файлов из одной папки).

Если браузер блокирует, поднимите статический сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Сборка в один файл

```bash
python3 build.py    # создаёт ../MudRacing.html — всё внутри одного HTML
```

Готовый файл не требует ни интернета, ни папки `src`.

## Как устроена игра

**Трасса.** Три ванны по 30–36 м, между ними перемычки 3–5 м. Две дорожки,
рельеф каждой генерируется отдельно: в каждой ванне свои ямы и отмели,
поэтому одна и та же ванна на дорожках 1 и 2 проходится по-разному.

**Тяга вместо скорости.** Высота рельефа и уровень воды дают глубину.
В воде важно не «сколько газа», а попадание в зелёную зону тахометра:
зона сужается с глубиной. Перелив — гидроудар (−25 % скорости), недобор —
пробуксовка, долгий перелив по песку — перегрев и остановка двигателя
на 1,6 с. Заезд длится ~18–21 с.

**Регламент.** Жеребьёвка на 4 серии: каждый едет 2 раза по одной дорожке
и 2 раза по другой. При нечётном числе участников в каждой серии кто-то
едет без пары. Победитель — по сумме четырёх времён, фальстарт +2.00 с.
Игрок едет по одному заезду в серии, остальные пары просчитываются тем же
кодом физики.

**Параметры в `src/core.js`** (объект `C`): `WATER` — уровень воды,
`FLOAT` — глубина, с которой квадроцикл всплывает, `PENALTY` — штраф
за фальстарт. Баланс скорости задаётся в `stepRider` (`vmax`, коэффициенты
ускорения) и в `zone()` — ширина зелёной зоны по глубине.

## Управление

- ↑ / W / Space — газ (удерживать)
- на тач-устройствах — палец по экрану или кнопка «ГАЗ»
- Enter — перейти к следующему экрану

## Технические заметки

- Canvas 2D, без библиотек и внешних запросов. Кадр укладывается в 16 мс
  на десктопе и в 20 мс на мобильной эмуляции (DPR ограничен 1.6 на узких
  экранах, градиенты кэшируются).
- `src/core.js` экспортирует `MR` и работает в Node — удобно прогонять
  баланс без браузера:

```js
const MR = require('./src/core.js');
const tr = MR.makeTrack(1);
for (let s of [0.2, 0.5, 0.9])
  console.log(s, MR.simRun(tr, 0, s, MR.rng(42)).total.toFixed(2));
```

- Звук запускается после первого касания — ограничение автоплея браузеров.
- Прогресс не сохраняется: чемпионат живёт в рамках одной вкладки.
